# DataBound AI - Full Stack Application

A comprehensive full-stack application combining Python backend with modern JavaScript frontend.

## Project Structure

```
.
├── backend/          # Python Flask/FastAPI backend
├── frontend/         # React/Vue.js frontend
├── docker-compose.yml
├── Dockerfile
├── .gitignore
└── requirements.txt
```

## Getting Started

### Prerequisites
- Python 3.8+
- Node.js 14+
- Docker (optional)

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

### Docker Setup

```bash
docker-compose up
```

## Features

- RESTful API backend
- Modern responsive frontend
- Database integration
- Authentication & Authorization
- Real-time updates
